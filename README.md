# City-Composer

This is the repository for beta builds of the City Composer game.

Features may be incomplete or missing. Not all planned features have been added. Expect bugs and instability. Please report all bugs in the Issues tab. This application has not been notarized by Apple so a warning may be showed when opening. This application requires an Apple Silicon Mac with macOS 14.0 or above.

Updates will be released in the following days. Check back here often.

To install, download the Zip file and unzip.
